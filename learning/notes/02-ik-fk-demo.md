# 02. IK/FK 学習デモの見方

## デモページ
`/learning/ik-fk` （開発サーバー起動後）

| 色 | 意味 |
|----|------|

## 観察ポイント

### FKモードで確かめること

1. **「肩 Pitch」を変える** → 上腕だけでなく前腕と手もまとめて動く
   → **親を動かすと子が追従する = 階層伝搬** の感覚
2. **「肘の曲げ」を変える** → 前腕と手だけが動く。上腕は動かない
   → 各関節が独立に角度を持つという FK の本質
3. **手の位置を特定の場所に持っていきたい** → 3つの肩角度 + 肘角度を手探りで調整する必要あり
   → FK で目標位置に合わせるのが**どれだけ面倒か**体感する

### IKモードで確かめること

1. **目標(紫)をどこかに動かす** → 肩・肘の角度が自動計算され、手が目標にぴったり合う
   → IK の価値。「どこに置きたいか」だけで済む
2. **目標を遠くに(> 0.8m)移動** → 「届かない」と表示され、腕が伸び切る
   → `d > L1 + L2` で到達不可能になる数学的境界
3. **ポールヒント(黄)を前方(Z正)に動かす** → 肘が前に曲がる
   **ポールヒントを後方(Z負)に動かす** → 肘が後ろに曲がる
   → **同じ手の位置でも、肘の曲がる向きが変わる** = 2ボーンIKの解の多義性をポールヒントで絞り込む仕組み
4. **ポールヒントを上(Y正)に動かす** → 肘が上に突き出す（人体では不自然）
   → 人体らしい動きには「肘は後方、膝は前方」が必要

### 骨の長さを変える

1. 上腕を長く、前腕を短く → 肘の位置が遠くなるが、到達可能範囲 `L1+L2` は同じなら届く
2. 両方を短くする → 到達可能範囲が狭まり、同じ目標でも届かなくなる

## デモの内部実装で使っている数式

### IKの肘角度（余弦定理）
```
cos(θ_inner) = (L1² + L2² - d²) / (2 × L1 × L2)
```
- `θ_inner`: 上腕と前腕のなす内角
- `L1`: 上腕長、`L2`: 前腕長、`d`: 肩→目標の距離

### IKの肩方向の決定
1. 肩→目標 のなす角 α を余弦定理で計算
   ```
   cos(α) = (L1² + d² - L2²) / (2 × L1 × d)
   ```
2. ポールヒントから目標線への垂線方向 `bendDir` を計算（外積＋射影）
3. 肘位置 = `toTarget × L1·cos(α) + bendDir × L1·sin(α)`

### FKの順計算
- 肩の回転を ZYX 順に行列として掛ける
- 上腕の基本方向 `(0,-1,0)` を回転して肘位置を得る
- ロドリゲスの公式で前腕を肘角度だけ回転

## このデモで学んだことと本番モーションの関係

- 本番プロジェクトの `ik-solver.ts` もほぼ同じ構造（2ボーンIK + ポールヒント）
- 違いは「両腕両脚の4本を同時に解く」「複数パス繰り返す」「関節角度クランプを追加」など
- **コアの数学は同じ**なので、このデモで余裕が出たら本物のコードが読みやすくなる
